# mavi-customer-journey-analysis-case-study
Business Analysis case study focused on analyzing the customer journey on Mavi's e-commerce website.

The analysis covers the customer journey from entering the website until successfully adding a product to the shopping cart.

## Objectives

- Analyze the customer journey and user flow
- Create a detailed customer flowchart
- Identify strengths and improvement opportunities
- Evaluate the experience from both customer and business perspectives
- Suggest possible improvements and business KPIs

## Files

- Presentation: Customer Journey Analysis
- Excel: Data Analysis Case Study
- Flowchart: Detailed Customer Journey Flow

## Note

This project was prepared as part of a Business Analyst case study.
The analysis is based on observations of the Mavi e-commerce website and represents an individual evaluation.
